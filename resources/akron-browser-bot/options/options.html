How it works

Akron runs an agent loop in the extension's service worker. It asks your chosen model what to do, then executes browser tools (read page, click, type, scroll, open tabs, screenshot) on the active tab. No account, no proxy, no server: your key goes straight from this browser to the provider.

Treat API keys like passwords. Anyone with access to this Chrome profile can read them. Revoke a key at the provider if you stop using it.
