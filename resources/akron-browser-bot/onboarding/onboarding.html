Akron Browser Bot by akronlogic.com

A browser agent that uses your own API key from any provider.

Checking your setup…
1

Add an API key

Pick Anthropic, OpenAI, Google Gemini, or any OpenAI-compatible endpoint (OpenRouter, Groq, Together, Ollama, LM Studio, vLLM…). Keys stay in this browser and go straight to the provider.

2

Open the side panel

Click the Akron toolbar icon, press Ctrl+Shift+E (⌘+Shift+E on Mac), or pin the side panel from Chrome's side-panel menu. Keep it open while a task runs.

3

Give it a task

Try “Summarize this page”, “Fill this form with test data”, or “Find the login button and click it”. Akron reads the page, acts on it, and shows every tool call as it goes.

What's included

Full page controlRead, click, type, scroll, navigate, hover, drag, upload files, and manage tabs and tab groups.
Trusted inputReal mouse and keyboard events through the Chrome DevTools Protocol for sites that ignore synthetic clicks.
ScreenshotsCapture the visible tab, a single element, or a full page, and show it inline.
Streaming repliesAnswers appear as the model writes them, with an automatic non-streaming fallback.
Plans & toolsA live plan panel plus collapsible cards for every tool call, its arguments, and its result.
Scheduled tasksRun prompts on a repeating timer in the background, with saved results and notifications.
Saved prompts & skillsReusable prompts in the side panel, and switchable instruction packs for forms, research, and QA.
Voice & attachmentsDictate with the microphone and attach images or text files to a message.
GIF recordingRecord the tab as an animated GIF of the agent working, encoded locally and downloaded.
Domain policyAllow or block sites, and optionally ask before Akron touches a new host.
Per-tool confirmationChoose which tools must ask for permission on every use.
Local onlyNo account, no proxy, no analytics. Keys stay in chrome.storage.local.

Privacy in one line

Page text, screenshots, and your prompts are sent only to the provider you configured. Nothing passes through an Akron server — there isn't one.

Treat API keys like passwords. Anyone with access to this Chrome profile can read them. Revoke a key at the provider when you stop using it.
