# Button

Quiet is the default. **Primary** (the ink) at most once per view, for the thing the page is for. Verb first, sentence case: “Buy ticket”. You provide the label as children and any native button attribute; `type` defaults to `button`. Keyboard: native — Tab to it, Enter or Space presses it; focus shows the `focus-ring` token. No icon-only buttons: an icon may lead the word, never replace it. No disabled style: a button that cannot act is left out, or the reason sits in text beside it.
