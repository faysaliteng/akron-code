# Field

A labelled text input with an optional hint and an optional error. You provide `label` (always visible — no placeholder-as-label), `hint`, `error` and any native input attribute (`type`, `autoComplete`, `defaultValue`…). The label is a real `<label for>`; hint and error are joined to the input with `aria-describedby`, and an error also sets `aria-invalid`. The error line starts with the cross glyph and is set in `danger-ink`, and the input's border thickens to 2px of `danger-ink`, so the state is not told by color alone. Write the error as what to do (“Enter the 6 letters printed on the ticket”), not what went wrong. An error that appears on submit is announced by moving focus to the first invalid field (or to an error summary that links to it); one revealed while typing wants a live region — the field itself stays quiet so it is not read twice. A further `aria-describedby` you pass is kept after the field's own. Focus shows the `focus-ring` token.
